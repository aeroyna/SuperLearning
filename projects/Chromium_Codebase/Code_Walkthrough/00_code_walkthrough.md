## 🔍 Exploring the Codebase

This section guides you through the directory structure and key code paths.

### 1. [Directory Structure](02_directory_structure.md)
*   **`/base`**: Common utilities (threading, strings, containers).
*   `/content`: The core browser code (multi-process system).
*   `/chrome`: The browser application (UI, extensions, settings).
*   `/third_party`: External libraries (Blink, Skia, V8).

### 3. [Key Classes](03_key_classes.md)
*   **WebContents**: The Tab.
*   **RenderFrameHost**: The Frame.
*   **BrowserContext**: The Profile.
