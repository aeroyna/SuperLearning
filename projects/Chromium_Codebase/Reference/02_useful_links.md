# Useful Links & Resources

**[⬅️ Back to Reference](00_reference.md)**

---

## 🔍 Code Search & Browsing

*   **[Chromium Code Search](https://source.chromium.org/chromium/chromium/src)**: The absolute best tool. Fast, indexed, cross-referenced.
*   **[Chromium Review (Gerrit)](https://chromium-review.googlesource.com/)**: See what others are changing. Great for learning by example.
*   **[Chromium Dash](https://chromiumdash.appspot.com/)**: Track commits, releases, and feature statuses.

---

## 📚 Official Documentation

*   **[Chromium Docs (In-Tree)](https://chromium.googlesource.com/chromium/src/+/main/docs/README.md)**: The source of truth. Always check the `docs/` folder in the source code.
*   **[Design Docs](https://www.chromium.org/developers/design-documents/)**: Historical and current design documents.
*   **[Chrome Developers](https://developer.chrome.com/)**: Web platform updates, usually from a web developer's perspective but useful for feature context.

---

## 💬 Community & Help

*   **[Chromium-dev Google Group](https://groups.google.com/a/chromium.org/g/chromium-dev)**: The main mailing list for high-level technical discussions.
*   **[Slack](https://chromium.slack.com/)**: (Requires invite/approval).
*   **[IRC/Discord]**: There are various informal communities, but the mailing list is official.

---

## 🎓 Deep Dives & Blogs

*   **[Life of a Pixel](https://docs.google.com/presentation/d/1boPxbgNrTE41tKWAGcMIVXnpxi_DscRUaW-nQ_8kOeo/edit)**: A legendary presentation by Steve Kobes.
*   **[V8 Blog](https://v8.dev/blog)**: Excellent technical articles on V8 internals.
*   **[BlinkOn](https://www.youtube.com/results?search_query=blinkon)**: Conference talks from the Blink team. Highly recommended.
