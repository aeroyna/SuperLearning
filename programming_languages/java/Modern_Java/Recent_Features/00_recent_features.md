# Recent Features (Java 9-21)

Java has accelerated its release cadence since Java 9. This chapter covers the most impactful features that have modernized the language.

## In this chapter, you will learn:
*   [**Records**](01_records.md): Boilerplate-free data classes with secure serialization.
*   [**Sealed Classes**](02_sealed_classes.md): Controlling class hierarchies and enabling exhaustive switching.
*   [**Pattern Matching**](03_pattern_matching.md): Simplifying `instanceof` and structure extraction.
*   [**Switch Expressions**](04_switch_expressions.md): Using switch as an expression with type matching.
*   [**Text Blocks**](05_text_blocks.md): Multi-line strings done right.
