# Optional Class

The "Billion Dollar Mistake" (Null References) is addressed in Java 8 with `java.util.Optional`. It is a container object which may or may not contain a non-null value.

## In this chapter, you will learn:
*   [**Optional Basics**](01_optional_basics.md): Correct usage patterns and serialization pitfalls.
*   [**Functional Style**](02_avoiding_null_checks.md): Using `map`, `flatMap`, and `orElse` to write fluent, null-safe code chains.
