# Functional Programming

Functional programming treats computation as the evaluation of mathematical functions and avoids changing state and mutable data. Java 8 introduced hybrid functional capabilities, allowing you to write cleaner, more declarative code.

## In this chapter, you will learn:
*   [**Lambda Expressions**](01_lambda_expressions.md): The syntax for passing code as data (`->`) and how the JVM optimizes them using `invokedynamic`.
*   [**Functional Interfaces**](02_functional_interfaces.md): Understanding the contract of single-abstract-method interfaces (`Predicate`, `Function`, etc.).
*   [**Method References**](03_method_references.md): The `::` shorthand types and how they bind to instances.
