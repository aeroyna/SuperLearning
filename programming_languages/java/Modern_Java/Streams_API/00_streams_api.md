# Streams API

The Streams API represents a modernization of the Java language, allowing for functional-style operations on streams of elements. It is the preferred way to process collections in modern Java.

## In this chapter, you will learn:
*   [**Stream Basics**](01_stream_basics.md): Creating streams and understanding lazy evaluation.
*   [**Intermediate Operations**](02_intermediate_operations.md): Transforming data lazily with `map`, `filter`, and stateless vs stateful ops.
*   [**Terminal Operations**](03_terminal_operations.md): Producing results with `collect`, `reduce`, and `forEach`.
*   [**Parallel Streams**](04_parallel_streams.md): Leveraging the Fork/Join pool and knowing when *not* to use it.
