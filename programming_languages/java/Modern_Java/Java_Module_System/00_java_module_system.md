# Java Module System

Java 9 introduced the biggest change in Java's history: The Java Platform Module System (JPMS). It moves beyond the flat classpath to a graph of strongly encapsulated modules.

## In this chapter, you will learn:
*   [**JPMS Basics**](01_jpms_basics.md): Concepts of strong encapsulation, the unnamed module, and solving classpath hell.
*   [**Directives**](02_module_descriptors.md): Using `exports`, `requires`, and `opens` to control module visibility and reflection access.
