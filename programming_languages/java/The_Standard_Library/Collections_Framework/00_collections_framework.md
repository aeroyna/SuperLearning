# Collections Framework

The Java Collections Framework (JCF) is the toolbox of data structures every Java developer uses daily. It provides high-performance, high-quality implementations of common data structures.

## In this chapter, you will learn:
*   [**The Hierarchy**](01_collection_hierarchy.md): The relationship between `Collection`, `List`, `Set`, and `Map`.
*   [**Lists**](02_list_interface_arraylist_linkedlist.md): When to use `ArrayList` (fast access) vs. `LinkedList` (fast insertion).
*   [**Sets**](03_set_interface_hashset_treeset.md): Understanding `HashSet` (fast) vs. `TreeSet` (sorted) for storing unique items.
*   [**Maps**](04_map_interface_hashmap_treemap.md): Storing key-value pairs with `HashMap` and `TreeMap`.
*   [**Queues**](05_queue_and_deque.md): Handling FIFO data with `PriorityQueue` and `Deque`.
*   [**Iterators**](06_iterator_and_iterable.md): The standard way to traverse collections safely.
