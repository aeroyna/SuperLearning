# New IO (NIO)

Introduced in Java 1.4 and expanded in Java 7 (NIO.2), New I/O offers non-blocking IO operations and a modern file system API. It is critical for high-performance applications.

## In this chapter, you will learn:
*   [**Buffers & Channels**](01_buffers_and_channels.md): The block-oriented approach to IO, contrasting with Stream-oriented IO.
*   [**NIO.2 Files**](02_path_and_files.md): The modern `Path` and `Files` classes for robust file manipulation.
*   [**Selectors**](03_selectors_and_async_io.md): How to build high-performance, non-blocking network servers that handle thousands of connections with a single thread.
