# Input/Output (IO)

This chapter covers the classic `java.io` package. While newer APIs exist, understanding Streams is essential for working with files, network sockets, and data serialization.

## In this chapter, you will learn:
*   [**File API**](01_file_class.md): The legacy way of managing file paths and metadata.
*   [**Byte Streams**](02_byte_streams.md): Reading and writing raw binary data (`InputStream`, `OutputStream`).
*   [**Character Streams**](03_character_streams.md): Handling text files correctly with `Reader` and `Writer`.
*   [**Serialization**](04_serialization.md): Persisting Java objects to disk and sending them over networks.
