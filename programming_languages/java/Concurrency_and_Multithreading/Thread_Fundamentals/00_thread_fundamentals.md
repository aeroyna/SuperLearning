# Thread Fundamentals

Concurrency is the art of doing multiple things at the same time. To understand Java concurrency, we must first understand the fundamental unit of execution: the Thread. This chapter explores the relationship between the Java `Thread` class and the underlying Operating System (OS).

## In this chapter, you will learn:
*   [**Process vs Thread**](01_process_vs_thread.md): Memory isolation, context switching costs, and the stack vs heap model.
*   [**Thread Lifecycle**](02_thread_lifecycle.md): The 6 states of a thread and how to interpret thread dumps.
*   [**Creating Threads**](03_creating_threads.md): `Runnable` vs `Thread` vs `Callable`.
