# Java Memory Model (JMM)

The JMM defines how the Java runtime interacts with computer memory (RAM). It is a specification that guarantees how and when different threads can see values written by other threads.

*   [**JMM Basics**](01_jmm_basics.md): Working memory vs Main memory abstraction.
*   [**Happens-Before Relationship**](02_happens_before_relationship.md): The rules that guarantee memory consistency.
*   [**Atomicity, Visibility, Ordering**](03_atomicity_visibility_ordering.md): The three pillars of concurrency bugs.
