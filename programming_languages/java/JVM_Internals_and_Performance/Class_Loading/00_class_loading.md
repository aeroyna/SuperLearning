# Class Loading

The Class Loading mechanism is dynamic and lazy. It allows Java to load code at runtime, enabling features like hot-swapping and plugin architectures.

## In this chapter, you will learn:
*   [**ClassLoader Subsystem**](01_classloader_subsystem.md): The delegation hierarchy (Bootstrap -> App) and class uniqueness.
*   [**Loading, Linking, Initialization**](02_loading_linking_initialization.md): The lifecycle of a class from file to memory.
