# Garbage Collection

Garbage Collection (GC) is the automatic process of looking at heap memory, identifying which objects are in use and which are not, and deleting the unused objects.

## In this chapter, you will learn:
*   [**GC Basics**](01_gc_basics.md): The Generational Hypothesis (Eden, Survivor, Old Gen).
*   [**GC Algorithms**](02_gc_algorithms_serial_parallel_cms_g1_zgc.md): Evolution from Serial to G1 and ZGC.
*   [**GC Tuning**](03_gc_tuning.md): Understanding Latency vs Throughput and basic tuning flags.
