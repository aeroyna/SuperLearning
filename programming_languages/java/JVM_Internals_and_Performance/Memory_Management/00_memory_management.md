# Memory Management

Memory management in Java is largely automated by the JVM, but understanding how it works is crucial for writing efficient applications and debugging memory leaks (`OutOfMemoryError`).

## In this chapter, you will learn:
*   [**Stack vs Heap**](01_stack_vs_heap.md): Thread-local frames vs Shared object storage.
*   [**Metaspace**](02_metaspace.md): Where class metadata lives (native memory).
*   [**Reference Types**](03_reference_types_weak_soft_phantom.md): Interacting with the GC using Weak, Soft, and Phantom references.
