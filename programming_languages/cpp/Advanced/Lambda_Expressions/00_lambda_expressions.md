# Lambda Expressions

Lambda expressions (or lambdas) are anonymous functions that can be defined inline. They are a powerful feature for writing concise and readable code, especially when working with STL algorithms or callbacks. This chapter covers the syntax of lambdas, how they capture variables from their surrounding scope (closures), and how to use them to create function objects on the fly.

You will learn about:
- **Lambda Syntax:** Defining inline functions.
- **Captures:** Accessing local variables by value or reference.
- **Generic Lambdas:** Writing lambdas that accept `auto` parameters.
- **Function Objects:** How lambdas relate to functors.
