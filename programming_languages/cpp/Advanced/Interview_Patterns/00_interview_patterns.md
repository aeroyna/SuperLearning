## Pattern Recognition

| Pattern | Problem Keywords |
|---------|-----------------|
| Two Pointer | sorted array, pairs, palindrome, remove duplicates |
| Sliding Window | subarray, substring, window, consecutive, maximum/minimum |
| Binary Search | sorted, search, minimize maximum, find boundary |
| Backtracking | all combinations, permutations, generate, valid configurations |
| Bit Manipulation | XOR, single number, power of two, subset |

## Why These Patterns Matter

Most interview problems are variations of these patterns. Recognizing which pattern applies is often the key insight needed to solve a problem efficiently.
