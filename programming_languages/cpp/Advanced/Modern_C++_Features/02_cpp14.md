# C++14 Features

C++14 was a smaller update compared to C++11, but it introduced several useful features that refine and extend the features of C++11.

## Core Language Features

*   **Generic Lambdas:** Lambdas can now use `auto` in their parameter list, making them act like function templates.
    ```cpp
    auto add = [](auto a, auto b) {
        return a + b;
    };
    ```

*   **Generalized Lambda Capture:** You can create new variables in the capture clause of a lambda. This is particularly useful for moving objects into a lambda.
    ```cpp
    auto ptr = std::make_unique<int>(10);
    auto my_lambda = [p = std::move(ptr)]() { /* use p */ };
    ```

*   **Function Return Type Deduction:** The return type of a normal function can be deduced by the compiler using `auto`.
    ```cpp
    auto my_function() {
        return 42; // returns int
    }
    ```

*   **Binary Literals:** You can specify binary literals using the `0b` or `0B` prefix.
    ```cpp
    int x = 0b101010; // 42
    ```

*   **Digit Separators:** You can use a single quote (`'`) as a digit separator to make large numbers more readable.
    ```cpp
    long long n = 1'000'000'000;
    ```

*   **`deprecated` attribute:** You can mark a function or class as deprecated to issue a warning at compile time if it is used.
    ```cpp
    [[deprecated("Use new_function instead")]]
    void old_function() { ... }
    ```

## Standard Library Features

*   **`std::make_unique`:** A helper function for creating `std::unique_ptr`s, analogous to `std::make_shared`. This was a much-requested feature that was missing from C++11.
    ```cpp
    auto ptr = std::make_unique<MyClass>();
    ```

*   **`std::shared_timed_mutex`:** A shared mutex that supports timed locking.

*   **User-defined literals for standard library types:** You can now create `std::string`, `std::complex`, and `std::chrono` duration objects with literals.
    ```cpp
    using namespace std::string_literals;
    auto s = "hello"s; // s is a std::string

    using namespace std::chrono_literals;
    auto t = 10s; // t is a std::chrono::seconds object
    ```

C++14 is often seen as a "quality of life" release that smoothed out some of the rough edges of C++11 and made the language more convenient to use.
