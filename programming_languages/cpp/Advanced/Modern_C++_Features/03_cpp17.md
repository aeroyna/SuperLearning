# C++17 Features

C++17 was another major update to the language, with a focus on improving everyday code and adding several large new library features.

## Core Language Features

*   **Structured Bindings:** Allows you to decompose an object (like a `struct`, `std::pair`, or `std::tuple`) into its constituent parts.
    ```cpp
    std::map<int, std::string> my_map = {{1, "one"}, {2, "two"}};
    for (const auto& [key, value] : my_map) {
        std::cout << key << ": " << value << std::endl;
    }
    ```

*   **`if` and `switch` with initializers:** You can now include an initializer in an `if` or `switch` statement. The initialized variable is scoped to the statement.
    ```cpp
    if (auto it = my_map.find(1); it != my_map.end()) {
        // use it here
    }
    // it is not visible here
    ```

*   **Fold Expressions:** A more concise way to apply an operator to a parameter pack in a variadic template.
    ```cpp
    template <typename... Args>
    auto sum(Args... args) {
        return (args + ...);
    }
    ```

*   **`constexpr if`:** A compile-time `if` statement. The condition must be a compile-time constant expression. The branch that is not taken is discarded at compile time.
    ```cpp
    template <typename T>
    auto get_value(T t) {
        if constexpr (std::is_pointer_v<T>) {
            return *t; // only compiles if T is a pointer
        } else {
            return t;
        }
    }
    ```

*   **Inline Variables:** You can now declare variables as `inline`, which allows you to define a global variable in a header file without violating the one-definition rule.

*   **Nested Namespaces:** You can define nested namespaces more concisely: `namespace A::B { ... }` instead of `namespace A { namespace B { ... } }`.

## Standard Library Features

*   **Parallel Algorithms:** Many of the STL algorithms now have parallel versions that can automatically distribute the work across multiple threads. You can specify an execution policy (`std::execution::par`).
    ```cpp
    std::sort(std::execution::par, vec.begin(), vec.end());
    ```

*   **`std::filesystem`:** A library for working with file systems, including paths, files, and directories.
    ```cpp
    #include <filesystem>
    namespace fs = std::filesystem;
    fs::path p = "/path/to/file.txt";
    if (fs::exists(p)) { ... }
    ```

*   **`std::optional`:** Represents an optional value. It can either contain a value or be empty. This is a safer alternative to using null pointers or special values to indicate the absence of a result.

*   **`std::variant`:** A type-safe union. An instance of `std::variant` can hold a value from a set of alternative types.

*   **`std::any`:** A type-safe container for a single value of any type.

*   **`std::string_view`:** A non-owning, read-only view of a string. It is useful for passing substrings to functions without making a copy.

C++17 added a lot of powerful new tools to the programmer's toolbox, especially in the standard library. Features like structured bindings and `if` with initializers have changed the way everyday C++ code is written.
