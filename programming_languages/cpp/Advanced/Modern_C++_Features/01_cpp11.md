# C++11 Features

C++11 was a major update to the C++ language that introduced a large number of new features. Many of these features have already been covered in other sections of this course. This section provides a summary of the most important C++11 features.

## Core Language Features

*   **`auto` keyword:** Automatic type deduction for variables.
    ```cpp
    auto i = 42; // i is an int
    auto d = 3.14; // d is a double
    ```

*   **Range-based `for` loop:** A more convenient way to iterate over a range.
    ```cpp
    std::vector<int> vec = {1, 2, 3};
    for (int x : vec) { ... }
    ```

*   **Lambda Expressions:** Anonymous function objects.
    ```cpp
    auto my_lambda = [](int x) { return x * 2; };
    ```

*   **Move Semantics and Rvalue References (`&&`):** Avoids unnecessary copies by "moving" resources from temporary objects. Includes move constructors and move assignment operators.

*   **`nullptr`:** A new keyword for null pointers, which is more type-safe than the old `NULL` macro.

*   **Initializer Lists:** A uniform syntax for initializing objects.
    ```cpp
    int x{5};
    std::vector<int> vec{1, 2, 3};
    ```

*   **`noexcept` specifier:** Declares that a function will not throw exceptions.

*   **`override` and `final` keywords:** `override` ensures that a virtual function is overriding a base class function. `final` prevents a class from being inherited or a virtual function from being overridden.

*   **`enum class` (Scoped Enums):** A more type-safe version of enums.
    ```cpp
    enum class Color { Red, Green, Blue };
    Color c = Color::Red;
    ```

*   **Variadic Templates:** Templates that can take a variable number of arguments.

## Standard Library Features

*   **Concurrency Library:**
    *   `std::thread`
    *   `std::mutex`, `std::lock_guard`, `std::unique_lock`
    *   `std::condition_variable`
    *   `std::atomic`
    *   `std::future`, `std::promise`, `std::async`

*   **Smart Pointers:**
    *   `std::unique_ptr`
    *   `std::shared_ptr`
    *   `std::weak_ptr`

*   **New Containers:**
    *   `std::array`: A fixed-size array container.
    *   `std::forward_list`: A singly-linked list.
    *   `std::unordered_map`, `std::unordered_set`: Hash-based associative containers.

*   **`std::tuple`:** A fixed-size collection of heterogeneous values.

*   **`std::function`:** A general-purpose polymorphic function wrapper.

*   **Type Traits Library (`<type_traits>`):** A set of tools for compile-time type introspection.

C++11 was a transformative release that made C++ a much more expressive, safer, and more powerful language. Most modern C++ code is written using C++11 or later standards.
