# C++20 Features

C++20 is the most recent major update to the C++ standard and arguably the biggest release since C++11. It introduces several groundbreaking new features.

## The "Big Four"

*   **Concepts:** Concepts are a long-awaited feature that allows you to place constraints on template parameters. This provides much clearer error messages when a template is instantiated with the wrong type and makes generic code easier to write and understand.
    ```cpp
    template <typename T>
    concept Integral = std::is_integral_v<T>;

    void my_function(Integral auto x) { ... } // x must be an integral type
    ```

*   **Ranges:** The ranges library provides a new way to work with sequences of elements. It introduces a `range` concept, which is anything that you can iterate over. It also provides "views", which are composable adaptors for ranges that allow you to express complex algorithms in a more declarative style.
    ```cpp
    #include <vector>
    #include <ranges>

    std::vector<int> numbers = {1, 2, 3, 4, 5, 6};
    auto even_squares = numbers
                      | std::views::filter([](int n) { return n % 2 == 0; })
                      | std::views::transform([](int n) { return n * n; });
    // even_squares is a view that contains {4, 16, 36}
    ```

*   **Coroutines:** Coroutines are special functions that can be suspended and resumed. They are a powerful tool for writing asynchronous code in a more sequential style, without the "callback hell" that can arise from traditional asynchronous programming. Coroutines are a complex feature and are often used in networking and other I/O-bound applications.

*   **Modules:** Modules are a new way to organize C++ code that is intended to be a replacement for header files. Modules provide better isolation, faster compile times, and an explicit way to declare interfaces.
    ```cpp
    // my_module.cppm
    export module my_module;
    export int add(int a, int b) { return a + b; }

    // main.cpp
    import my_module;
    int main() { return add(2, 2); }
    ```

## Other Important Features

*   **Three-way comparison operator (`<=>`):** The "spaceship operator" simplifies the process of writing comparison operators. It returns a value that indicates whether the left operand is less than, equal to, or greater than the right operand.
    ```cpp
    // Instead of writing ==, !=, <, >, <=, >=, you can just write:
    auto operator<=>(const MyClass& other) const = default;
    ```

*   **`consteval` and `constinit`:** `consteval` is used to declare a function that must be evaluated at compile time. `constinit` is used to declare a variable that must be initialized at compile time.

*   **Calendar and Time Zone Library:** A major extension to the `<chrono>` library that adds support for working with dates, calendars, and time zones.

*   **`std::span`:** A non-owning view of a contiguous sequence of objects. It's like `std::string_view`, but for any type of array.

*   **Bit manipulation library (`<bit>`):** Provides functions for common bitwise operations.

C++20 is a huge release that is still being rolled out in compilers and libraries. Features like concepts and ranges are set to fundamentally change the way C++ code is written.
