# Inheritance

Inheritance allows a class (derived class) to acquire the properties and behaviors of another class (base class). It promotes code reusability and establishes a hierarchical relationship between classes. This chapter covers the different types of inheritance, how constructors and destructors behave in a hierarchy, and the implications of access specifiers on inherited members.

You will learn about:
- **Base & Derived Classes:** The IS-A relationship.
- **Access Specifiers:** `public`, `protected`, and `private` inheritance.
- **Method Overriding:** Redefining base class behavior.
- **Composition vs. Inheritance:** Choosing the right relationship.
