# Constructors and Destructors

Constructors and destructors are special member functions that manage the lifecycle of an object. Constructors initialize the object's state when it is created, while destructors perform cleanup when the object is destroyed. Understanding these functions is crucial for resource management, ensuring that objects are always in a valid state and that resources (like memory or file handles) are properly released.

You will learn about:
- **Default & Parameterized Constructors:** Different ways to initialize objects.
- **Member Initializer Lists:** The efficient way to initialize members.
- **Destructors:** The syntax and timing of object destruction.
- **Copy Constructors:** Creating new objects as copies of existing ones.
