# Polymorphism

Polymorphism is the ability of objects to take on many forms. In C++, this allows a single interface to represent different underlying forms (data types). It is primarily achieved through function overloading (compile-time) and virtual functions (runtime). This chapter focuses on runtime polymorphism, which allows derived classes to be treated as base classes, enabling flexible and extensible systems.

You will learn about:
- **Virtual Functions:** Enabling dynamic dispatch.
- **`override` and `final`:** Modern keywords for safe overriding.
- **Abstract Classes & Pure Virtual Functions:** Defining interfaces.
- **V-Table:** The internal mechanism behind virtual functions.
