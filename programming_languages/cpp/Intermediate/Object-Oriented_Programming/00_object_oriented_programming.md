# Object-Oriented Programming

Object-Oriented Programming (OOP) is a programming paradigm based on the concept of "objects," which can contain data (attributes) and code (methods). C++ is a multi-paradigm language with strong support for OOP. This chapter covers the four fundamental pillars of OOP: Encapsulation, Abstraction, Inheritance, and Polymorphism. You will learn how to design systems that are modular, reusable, and easy to maintain by modeling real-world entities as classes and objects.

You will learn about:
- **Classes & Objects:** The blueprint and the instance.
- **Lifecycle Management:** How objects are created and destroyed.
- **The 4 Pillars:** Structuring code for security and flexibility.
- **Relationships:** How objects interact and inherit behaviors.
