# Algorithms

The STL provides a rich collection of algorithms to act on the contents of containers. These algorithms include sorting, searching, manipulating, and counting. They are implemented as function templates and operate on ranges of elements defined by iterators. This decoupling allows the same algorithm to work with different types of containers.

You will learn about:
- **Non-modifying Algorithms:** Searching and counting (e.g., `find`, `count`).
- **Modifying Algorithms:** Changing order or values (e.g., `sort`, `transform`, `copy`).
- **Algorithm Efficiency:** Understanding the underlying complexity.
