# Containers

Containers are objects that hold data. The STL provides a variety of containers that are implemented as class templates, allowing them to hold elements of any type. They are classified into sequence containers (like `vector`, `list`, `deque`), associative containers (like `set`, `map`), and unordered associative containers. Choosing the right container is critical for the performance of your application.

You will learn about:
- **Sequence Containers:** Storing elements in a strict linear order.
- **Associative Containers:** Storing elements in sorted order for fast retrieval.
- **Time Complexity:** The Big-O performance of insertions, deletions, and access for each container.
