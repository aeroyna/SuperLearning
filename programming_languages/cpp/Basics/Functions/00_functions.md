# Functions

Functions are the building blocks of modular programming in C++. They allow you to encapsulate code into reusable units, making programs easier to write, read, and maintain. A deep understanding of functions involves knowing how parameters are passed (by value vs. by reference), how stack frames are created and destroyed during execution, and how the return values are handled. This chapter also introduces the concepts of overloading and recursion, which provide powerful ways to structure your logic.

You will learn about:
- **Declaration & Definition:** Separating the interface from the implementation.
- **Parameter Passing:** The mechanics and performance implications of passing data to functions.
- **Overloading:** Creating multiple functions with the same name but different parameters.
- **Recursion:** Solving problems by having functions call themselves.
