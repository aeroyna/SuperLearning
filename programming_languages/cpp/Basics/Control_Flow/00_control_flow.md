# Control Flow

Control flow statements determine the order in which individual statements, instructions, or function calls are executed or evaluated. Without control flow, a program is merely a list of statements executed sequentially. This chapter introduces the mechanisms that allow your program to make decisions (selection), repeat actions (iteration), and jump to different parts of the code (jumps). Mastering these concepts is essential for writing algorithms that can handle varying inputs and logic.

You will learn about:
- **Selection Statements:** Using `if`, `else if`, `else`, and `switch` to execute code based on conditions.
- **Iteration Statements:** Using `for`, `while`, and `do-while` loops to repeat blocks of code.
- **Jump Statements:** Using `break`, `continue`, and `return` to alter the natural flow of loops and functions.
