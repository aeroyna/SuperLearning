# Variables and Data Types

In C++, variables are the fundamental units for storing data, and data types define the nature of that data—how much memory it occupies and how the bit pattern is interpreted. Understanding the type system is critical in C++ because it is a statically typed language; every variable must have a known type at compile time. This chapter explores how to declare, initialize, and manage variables, as well as the rich set of primitive types available to optimize memory usage and performance.

You will learn about:
- **Variable Declaration & Initialization:** The rules for naming and creating variables, and the difference between definition and declaration.
- **Fundamental Data Types:** Integers, floating-point numbers, characters, and booleans.
- **Type Modifiers:** How keywords like `signed`, `unsigned`, `short`, and `long` alter the size and range of types.
- **Type Safety:** The implications of implicit conversions and casting.
