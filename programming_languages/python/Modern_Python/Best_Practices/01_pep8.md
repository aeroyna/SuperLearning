# PEP 8 - Style Guide

PEP 8 is the style guide for Python code. Adhering to it ensures your code is readable by other Python developers.

## Key Rules

### Indentation
*   Use **4 spaces** per indentation level.
*   Do NOT use tabs.

### Line Length
*   Limit all lines to a maximum of **79 characters**.
*   For docstrings or comments, limit to 72 characters.

### Imports
*   Imports should usually be on separate lines.
*   Order:
    1.  Standard library imports.
    2.  Related third-party imports.
    3.  Local application/library specific imports.

```python
import os
import sys

import requests

from myproject import utils
```

### Whitespace
*   Avoid extraneous whitespace.
    *   Yes: `spam(ham[1], {eggs: 2})`
    *   No:  `spam( ham[ 1 ], { eggs: 2 } )`

### Naming Conventions
*   `Snake_Case`: Modules, Variables, Functions, Methods (`my_variable`, `calculate_total`)
*   `PascalCase`: Classes, Exceptions (`MyClass`, `ValueError`)
*   `CONSTANT_CASE`: Constants (`MAX_OVERFLOW`)

## Tools
Don't memorize this. Use a linter.
*   `flake8`: Checks PEP 8 compliance.
*   `black`: Auto-formats code to be PEP 8 compliant (uncompromising).
