# Data Structures & Algorithms - Interview Preparation

A comprehensive DSA learning path designed for technical interviews at top companies (Google, Microsoft, Amazon, Adobe, NVIDIA, Meta, etc.).

## Target Audience

This curriculum is designed for candidates preparing for:
- Software Engineering Interviews at FAANG/MAANG companies
- System Design rounds that require DSA knowledge
- Online Assessments (OA) and coding challenges
- Competitive programming foundations

## Study Plan Recommendations

### 2-Week Intensive
Focus on: Arrays, Strings, Hash Maps, Two Pointers, Sliding Window, Binary Search, BFS/DFS, Basic DP

### 4-Week Comprehensive
Add: Linked Lists, Stacks/Queues, Trees (all types), Heaps, Backtracking, Advanced DP, Greedy

### 8-Week Complete
Add: Graphs (all algorithms), Tries, Advanced Trees, Bit Manipulation, All problem patterns, Company-specific prep

## Key Topics by Frequency (Based on Interview Data)

### Most Frequently Asked
1. Arrays and Strings (Two Pointers, Sliding Window)
2. Hash Maps and Sets
3. Binary Trees and BSTs
4. Dynamic Programming
5. BFS/DFS (Trees and Graphs)
6. Binary Search

### Commonly Asked
7. Linked Lists
8. Stacks and Queues
9. Heaps/Priority Queues
10. Backtracking
11. Greedy Algorithms

### Less Common but Important
12. Tries
13. Union-Find
14. Topological Sort
15. Segment Trees / Fenwick Trees
16. Advanced Graph Algorithms
