## Interview Success Factors

### Technical Skills (40%)
- Data structure and algorithm knowledge
- Code implementation ability
- Complexity analysis

### Problem-Solving Process (40%)
- Clarifying questions
- Breaking down problems
- Considering edge cases
- Incremental approach

### Communication (20%)
- Clear explanation of thought process
- Receiving and incorporating feedback
- Professional interaction

## The UMPIRE Framework

A systematic approach to solving any interview problem:

**U - Understand**
- Restate the problem in your own words
- Clarify inputs, outputs, and constraints
- Ask about edge cases
- Confirm examples

**M - Match**
- Identify similar problems you've seen
- Recognize applicable patterns
- Consider relevant data structures

**P - Plan**
- Outline your approach before coding
- Discuss time/space complexity
- Get interviewer buy-in

**I - Implement**
- Write clean, readable code
- Use meaningful variable names
- Think out loud while coding

**R - Review**
- Walk through your code with an example
- Check edge cases
- Verify complexity analysis

**E - Evaluate**
- Discuss trade-offs
- Consider optimizations
- Mention alternative approaches

## Common Pitfalls to Avoid

1. **Jumping to code immediately**: Always clarify and plan first
2. **Silent coding**: Keep communicating your thought process
3. **Ignoring hints**: Interviewers give hints for a reason
4. **Overcomplicating**: Start with brute force, then optimize
5. **Not testing**: Walk through your code with examples
6. **Poor time management**: Don't spend too long on one part

## Study Plan by Timeline

### 1 Week
- Focus on most frequent patterns (arrays, hash maps, trees)
- Practice 2-3 problems daily
- Review complexity analysis

### 2 Weeks
- Add linked lists, stacks, queues, heaps
- Start BFS/DFS problems
- Practice 3-4 problems daily

### 4 Weeks
- Add dynamic programming basics
- Include graph algorithms
- Practice 4-5 problems daily
- Start mock interviews

### 8+ Weeks
- Cover all topics comprehensively
- Focus on weak areas
- Regular mock interviews
- Company-specific preparation
