# Adobe Linked Lists Patterns

**Frequency**: 🟡 **Medium**

Adobe frequently tests basic to intermediate linked list manipulations. Merging, reversing, and cycle detection are the core themes.

## Key Concepts
- **Reversal**: Changing pointer directions.
- **Two Pointers**: Fast/slow for cycles and middle finding.
- **Merging**: Combining sorted lists.
