# Amazon Trees & Graphs Patterns

**Frequency**: 🔴 **Very High**

Amazon heavily tests knowledge of trees and graphs, including various traversals, properties of BSTs, and shortest path algorithms. Grid problems (often framed as graph problems) are also very common.

## Key Concepts
- **BFS/DFS Traversals**: Fundamental for both trees and graphs (connected components, shortest paths).
- **BST Properties**: Inorder traversal, validation, insertion/deletion.
- **Tree Properties**: Height, diameter, path sums.
- **Union-Find**: For connectivity problems.
- **Topological Sort**: For task scheduling.
