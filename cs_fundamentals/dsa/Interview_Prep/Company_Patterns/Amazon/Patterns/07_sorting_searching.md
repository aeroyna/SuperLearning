# Amazon Sorting & Searching Patterns

**Frequency**: 🟡 **Medium**

Sorting and Searching are fundamental algorithms. Amazon often tests the efficient application of these, especially Binary Search on sorted data or on the "answer space".

## Key Concepts
- **Binary Search**: For sorted arrays, finding boundaries, or optimizing searches.
- **Custom Sorting**: Using lambda functions or comparators to sort complex objects.
- **Two Pointers**: Used in conjunction with sorting (e.g., `3Sum`).
