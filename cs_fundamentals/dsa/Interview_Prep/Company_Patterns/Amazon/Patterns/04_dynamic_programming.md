# Amazon Dynamic Programming Patterns

**Frequency**: 🟠 **High**

Dynamic Programming questions are common at Amazon, covering a range of problems from simple 1D DP to more complex 2D grid and string-based DP. Often, these problems can be solved with memoized recursion.

## Key Concepts
- **Memoization**: Top-down approach, storing results of subproblems.
- **Tabulation**: Bottom-up approach, building up solutions iteratively.
- **State Definition**: Crucial for correctly formulating the DP recurrence.
- **Space Optimization**: Reducing space complexity from 2D to 1D arrays.
