# Amazon Arrays & Strings Patterns

**Frequency**: 🔴 **Very High**

Amazon's interviews frequently feature problems involving array and string manipulation, emphasizing efficient in-place solutions and handling edge cases. Two Pointers and Sliding Window techniques are crucial here.

## Key Concepts
- **Two Pointers**: Used for problems like `Trapping Rain Water`, `Container With Most Water`, and `Valid Palindrome`.
- **Sliding Window**: Essential for finding substrings/subarrays with specific properties (e.g., `Longest Substring Without Repeating Characters`, `Minimum Window Substring`).
- **In-place Manipulation**: Optimizing space by modifying the input directly.
- **Character Frequencies**: Using hash maps or arrays to count character occurrences.
