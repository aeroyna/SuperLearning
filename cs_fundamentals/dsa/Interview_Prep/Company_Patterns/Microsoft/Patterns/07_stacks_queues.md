# Microsoft Stacks & Queues Patterns

**Frequency**: 🟡 **Medium**

Stack and Queue problems are common because they test logical thinking and data structure application without requiring complex algorithms. Calculator problems and parenthesis validation are classic Microsoft questions.

## Key Concepts
- **Stack**: LIFO (Last In, First Out). Essential for parsing, recursion simulation, and monotonic properties.
- **Queue**: FIFO (First In, First Out). Essential for BFS and processing streams.
- **Monotonic Stack**: Finding next greater/smaller element efficiently.
