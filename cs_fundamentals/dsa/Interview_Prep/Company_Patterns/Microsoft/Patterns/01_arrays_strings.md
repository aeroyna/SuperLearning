# Microsoft Arrays & Strings Patterns

**Frequency**: 🔴 **Very High**

Microsoft places a huge emphasis on array and string manipulation. These problems test your ability to handle edge cases, optimize space, and implement standard algorithms (Two Pointers, Sliding Window) cleanly.

## Key Concepts
- **Two Pointers**: Moving from ends or merging sorted arrays.
- **Sliding Window**: Finding substrings or subarrays with specific properties.
- **In-place Manipulation**: Modifying arrays without extra space (e.g., removing elements).
- **String Parsing**: Handling complex string formats (integers, paths, etc.).
