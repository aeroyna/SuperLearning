# Microsoft Linked Lists Patterns

**Frequency**: 🟠 **High**

Microsoft interviews often feature Linked List problems because they test pointer manipulation and handling edge cases (null checks, cycles) without complex algorithms.

## Key Concepts
- **Reversal**: Reversing the whole list or parts of it.
- **Two Pointers**: Fast/Slow for cycles or middle finding.
- **Dummy Node**: Simplifying head operations.
- **Deep Copy**: Handling random pointers.
