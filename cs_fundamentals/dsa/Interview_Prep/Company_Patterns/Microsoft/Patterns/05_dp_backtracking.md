# Microsoft DP & Backtracking Patterns

**Frequency**: 🟡 **Medium**

While less dominant than arrays or trees, Microsoft asks standard DP and Backtracking questions. They often focus on grid paths, subsets, and string combinations.

## Key Concepts
- **Grid DP**: Counting paths or finding min/max costs in a matrix.
- **1D DP**: Optimizing linear problems (House Robber, Stocks).
- **Backtracking**: Generating permutations, combinations, or searching in grids (Word Search).
