# Microsoft Trees & Graphs Patterns

**Frequency**: 🔴 **Very High**

Graph and Tree problems are staples at Microsoft. The focus is on standard traversals (BFS/DFS), finding paths, and validating structures (BSTs, connectivity). "Rotting Oranges" is a particularly famous Microsoft problem.

## Key Concepts
- **BFS (Level Order)**: Fundamental for tree levels and shortest paths in unweighted graphs.
- **DFS (Recursive)**: Essential for tree properties (height, symmetry) and path finding.
- **Matrix BFS/DFS**: Treating grids as graphs (Islands, Rotting Oranges).
- **BST Properties**: Inorder traversal yields sorted values.
