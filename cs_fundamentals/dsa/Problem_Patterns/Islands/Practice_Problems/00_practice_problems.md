# Practice Problems: Islands

Grid traversal and connected components.

| Problem | Difficulty | Key Insight |
|---------|------------|-------------|
| [Number of Islands](https://leetcode.com/problems/number-of-islands/) | Medium | DFS/BFS to mark connected '1's as visited. |
| [Max Area of Island](https://leetcode.com/problems/max-area-of-island/) | Medium | DFS returns count of nodes in component. |
| [Flood Fill](https://leetcode.com/problems/flood-fill/) | Easy | DFS starting from pixel, change color if matches source. |
| [Rotting Oranges](https://leetcode.com/problems/rotting-oranges/) | Medium | Multi-source BFS from all rotten oranges. |
| [Surrounded Regions](https://leetcode.com/problems/surrounded-regions/) | Medium | DFS from boundary 'O's. Flip remaining 'O's to 'X'. |
| [Word Search](https://leetcode.com/problems/word-search/) | Medium | DFS + Backtracking. |
| [Pacific Atlantic Water Flow](https://leetcode.com/problems/pacific-atlantic-water-flow/) | Medium | DFS from ocean boundaries inward. Intersect reachable sets. |
