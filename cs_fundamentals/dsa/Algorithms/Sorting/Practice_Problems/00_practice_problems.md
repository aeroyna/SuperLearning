# Practice Problems: Sorting

Mastering standard sorting algorithms and custom comparator logic.

## Fundamental Sorts

| Problem | Difficulty | Key Insight |
|---------|------------|-------------|
| [Sort an Array](https://leetcode.com/problems/sort-an-array/) | Medium | Implement Merge Sort or Randomized Quick Sort (Heap Sort also works). |
| [Sort Colors](https://leetcode.com/problems/sort-colors/) | Medium | Dutch National Flag problem (3-way partition). |
| [Insertion Sort List](https://leetcode.com/problems/insertion-sort-list/) | Medium | Linked List sorting. |

## Custom Sorting & Buckets

| Problem | Difficulty | Key Insight |
|---------|------------|-------------|
| [Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/) | Medium | Bucket Sort (freq as index) or QuickSelect. |
| [Sort Characters By Frequency](https://leetcode.com/problems/sort-characters-by-frequency/) | Medium | HashMap count + sort by value or Bucket Sort. |
| [Maximum Gap](https://leetcode.com/problems/maximum-gap/) | Hard | Bucket Sort (Pigeonhole Principle). |
| [Rank Teams by Votes](https://leetcode.com/problems/rank-teams-by-votes/) | Medium | Custom comparator sorting based on position counts. |
