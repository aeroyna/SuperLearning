# Protection and Security

## Overview

Protection and security are critical concerns in modern operating systems. Understanding these concepts is important for system design and interviews.

## Topics Covered

1. **[Protection Mechanisms](01_protection_mechanisms.md)**
   - Goals of protection
   - Principles of protection
   - Domain of protection
   - Protection rings (Ring 0-3)
   - Capability-based systems

2. **[Access Control](02_access_control.md)**
   - Access control matrix
   - Access control lists (ACL)
   - Capability lists
   - Unix file permissions
   - Role-based access control (RBAC)
   - Mandatory vs discretionary access control

3. **[Security Threats](03_security_threats.md)**
   - Types of threats (malware, viruses, worms, trojans)
   - Attack vectors
   - Buffer overflow attacks
   - Privilege escalation
   - Social engineering

4. **[Authentication](04_authentication.md)**
   - Password-based authentication
   - Multi-factor authentication
   - Biometric authentication
   - Kerberos
   - Public key infrastructure

## Key Takeaways

- Protection prevents authorized users from misusing resources
- Security prevents unauthorized access
- Access control mechanisms enforce policies
- Multiple layers of defense are necessary

## Interview Focus

- Explain protection vs security
- Understand access control mechanisms
- Know common security threats
- Describe authentication methods
