# Introduction to Operating Systems

## Overview

This chapter introduces the fundamental concepts of operating systems, their role in computer systems, and how they provide services to both users and applications.

## Topics Covered

1. **[What is an Operating System?](01_what_is_an_os.md)**
   - Definition and role
   - OS as a resource manager
   - OS as an extended machine
   - Goals of an operating system

2. **[Operating System Services](02_os_services.md)**
   - User-oriented services
   - System-oriented services
   - User interfaces (CLI, GUI, Touch)
   - System programs

3. **[System Calls](03_system_calls.md)**
   - What are system calls?
   - Types of system calls (process control, file management, device management, information maintenance, communication)
   - System call implementation
   - Examples: fork(), exec(), open(), read(), write()

4. **[Operating System Types](04_os_types.md)**
   - Batch systems
   - Time-sharing systems
   - Real-time systems
   - Distributed systems
   - Embedded systems

## Key Takeaways

- An OS acts as an intermediary between users/applications and hardware
- System calls provide the interface between processes and the operating system
- Different types of OS are designed for different use cases

## Interview Focus

- Understand the dual role of an OS: resource manager and abstraction layer
- Be able to explain common system calls and their purposes
- Know the differences between various OS types
