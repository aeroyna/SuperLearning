# Computer System Organization

## Overview

Understanding how computer systems are organized is fundamental to understanding how operating systems work. This chapter covers the hardware foundation upon which operating systems are built.

## Topics Covered

1. **[Computer System Operation](01_computer_system_operation.md)**
   - Boot process
   - CPU, memory, and I/O devices
   - System bus
   - Von Neumann architecture

2. **[Storage Structure](02_storage_structure.md)**
   - Storage hierarchy
   - Registers, cache, main memory
   - Secondary storage (HDD, SSD)
   - Tertiary storage
   - Volatility and performance trade-offs

3. **[I/O Structure](03_io_structure.md)**
   - I/O devices and controllers
   - Device drivers
   - Polling vs interrupts
   - Direct Memory Access (DMA)

4. **[Interrupts and Exceptions](04_interrupts_and_exceptions.md)**
   - What are interrupts?
   - Interrupt handling
   - Interrupt vector table
   - Hardware vs software interrupts
   - Exceptions and traps

## Key Takeaways

- Storage hierarchy balances speed, cost, and capacity
- I/O operations can be handled through polling, interrupts, or DMA
- Interrupts are crucial for efficient CPU utilization

## Interview Focus

- Explain the storage hierarchy and trade-offs
- Describe interrupt handling mechanism
- Understand DMA and why it's important
