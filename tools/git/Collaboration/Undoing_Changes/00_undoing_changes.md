# Chapter 6: Undoing Changes

One of git's superpowers - you can undo almost anything! But with power comes complexity. Let's break it down clearly.

## The Three Main Undo Commands

- **`git restore`** - Undo changes in working directory or staging (newer, clearer)
- **`git reset`** - Move branch pointer, optionally change staging/working directory
- **`git revert`** - Create new commit that undoes an old commit (safe for shared history)
