# Chapter 7: Advanced Workflow Tools

Master advanced workflow tools that help you manage your work efficiently without committing.

## Topics Covered

- **Git Stash** - Save work temporarily without committing
- **Git Worktrees** - Work on multiple branches simultaneously
- **Cherry-Pick** - Apply specific commits selectively
